# Iniciativa de ley de Inteligencia Artificial del Estado de Chihuahua

Este repositorio es para realizar una discusión comunitaria de la ley de 
Inteligencia Artificial del estado de Chihuahua.

Archivos originales:

* [Formato PDF](files/iniciativa_ley_ia_cuu.pdf)
* [Formato docx](files/iniciativa_ley_ia_cuu.docx)

## Instrucciones

Para facilitar la edición y contribuciones, existe un documento en
formato markdown: [iniciativa_ley_ia_cuu.md](iniciativa_ley_ia_cuu.md).

* Si deseas hacer comentarios crea un [issue](https://github.com/imcsk8/ley-ia-cuu/issues)
* Si deseas hacer una corrección on una contribución crea un pull request.

[!NOTE]

Comentarios negativos, ofensivos o politizados serán eliminados sin discusión ni previo aviso
el propósito de este repositorio es crear un enlace entre los interesados y
la mesa de trabajo de la iniciativa de ley. Existen otros espacios para las temáticas
antes mencionadas.
